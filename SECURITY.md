# Security Policy

Only the latest released version of MEX receives security fixes.

Report a suspected vulnerability privately to
[taivo@pungas.ee](mailto:taivo@pungas.ee) with the subject `MEX security report`.
Do not open a public issue. Include the MEX version, operating system, impact,
and the smallest safe reproduction you can provide. Do not attach sensitive
media; ask for a secure transfer method if a sample is necessary.
